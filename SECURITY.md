# Security Policy

This tool runs locally, collects no data, sends nothing anywhere, and needs no API key or secret. It only reads the CSS or pairs file you name, and it never changes any file. It writes nothing except the report on standard output (and standard error for skipped rules).

If you find a case where the tool changes a file, or reports a ratio that does not match the WCAG math for the two colours, please open an issue describing the exact commands and input. Do not include any real secret in the report.
